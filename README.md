# dealer-leaderboard

Leaderboard for the Rossi & Associates dealership referral contest: $750 for 1st place and $500 for 2nd place each month, by most quoted referrals.

Live page: https://rossiassociates.github.io/dealer-leaderboard/

`index.html` is generated from the agency's referral log and refreshed every weekday morning. It holds salesperson names, dealerships and monthly referral counts only, with no customer information. Don't edit it by hand; changes are overwritten on the next refresh.
